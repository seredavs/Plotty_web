# 🎬 Plotty — Пространство для историй

**Plotty** — это единая платформа для сценаристов, писателей и контент-мейкеров. Забудьте о разрозненных заметках и потерянных файлах: здесь структура, форматирование и командная работа живут в одном эстетичном пространстве.

## 🌟 Ключевые возможности

- 🗂 **Канбан-доска сюжета:** Организуйте акты и сцены визуально. Меняйте порядок перетаскиванием, не ломая текст.
- ✍️ **Умный редактор:** Пишите без отвлечений. Автоматическое форматирование под стандарт индустрии («американка»).
- 🕰 **История ревизий (Diff):** Сохраняйте версии, сравнивайте тексты бок о бок и мгновенно восстанавливайте удачные идеи.
- 🧠 **База знаний:** Единый реестр персонажей и локаций с цветовым кодированием и отслеживанием их появления в сценах.
- 🤝 **Командная работа:** Объединяйтесь в Организации, назначайте роли (Директор, Редактор, Комментатор) и обсуждайте сцены прямо в редакторе.

## 🛠 Технологии (Frontend UI)

- **HTML5 / CSS3** — семантическая верстка, Flexbox/Grid, кастомные UI-компоненты.
- **Vanilla JS** — интерактивность (модальные окна, драг-н-дроп, фильтры, аккордеоны) без перегрузки тяжелыми фреймворками.
- **Типографика** — шрифты Inter, Lora, Montserrat для идеальной читаемости и книжной эстетики.

## 🚀 Как запустить проект локально

Проект представляет собой набор сверстанных статических страниц, сервер для их просмотра не требуется.

1. Скачайте репозиторий;

2. Перейдите в папку с проектом;

3. Откройте файл `index.html` (лендинг) или любую страницу из папки `pages` (например, `board.html`) в вашем браузере.
